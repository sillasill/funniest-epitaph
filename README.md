The funniest possible famous last words as a single tombstone epitaph of at
most 150 characters: a one-line dying speech, carved-in-stone short, with a
surprise twist at the end — the heroic "died doing what he loved" setup
undercut by the most mundane modern obsession. Written for make.fun's
"Famous Last Words: The Funniest Epitaph" bounty, $2 in USDC.

Bounty: [Famous Last Words: The Funniest Epitaph](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406)

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the epitaph — one
line, well under the 150-character cap — to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The text is a constant: no
randomness, no clock, no network, so every run produces byte-identical
output.
